WebWindows

Runs a 32-bit or 64-bit Windows program from a folder on this computer. The program is translated to WebAssembly here in the browser and cached for the next launch; nothing is uploaded. Windowed programs run on Wine and appear below.

This browser has no 64-bit WebAssembly memory (Safari and every browser on iOS do not yet), so 64-bit programs run in a 32-bit memory, with less room than in Chrome or Firefox.
