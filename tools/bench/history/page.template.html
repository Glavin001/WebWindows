Start-up and code size

Cold start boots Wine with nothing translated yet (every DLL translated and compiled); warm start reuses the translation cache. Code size is all translated WebAssembly the four programs needed, Wine's DLLs included. The browser ships Wine's DLLs translated ahead of time, so the cold start is a one-time cost in Node; its jump at the second checkpoint (reducible loops) is worth a look.
